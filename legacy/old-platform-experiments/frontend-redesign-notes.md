## Frontend redesign notes

### Global
- Reduce shell padding, header height, card radius, and empty-state height.
- Standardize compact page headers, stat cards, tables, badges, and workspace tabs.
- Keep the calm medical palette, but shift the interface toward a denser operations-console layout.

### Live
- Promote a compact control strip above the fold.
- Make preview and current runtime state visible in the first viewport.
- Push setup, diagnostics, and onboarding into tabs, compact panels, and collapsible sections.
- Replace verbose guidance with short operational cues and direct status language.

### Overview
- Compress the header and metrics row.
- Pull jobs, events, and fleet status closer together with tighter table containers.
- Replace large empty areas with small, actionable placeholders.

### Login
- Keep branding, but reduce hero copy and visual weight.
- Make the sign-in form dominant and move API connection into an advanced section.
- Tighten the auth mode switch, field spacing, and helper text so the page reads like a secure console.
